# Ylham dagy

Полный проект сайта и серверной части компании Ylham dagy Hojalyk jemgyýeti.

## Скачать проект

[Скачать Ylham-dagy-complete.zip](./Ylham-dagy-complete.zip)

В архиве сохранена исходная структура проекта, 251 файл и ведомость контрольных сумм. Распакуйте архив в отдельную папку; подробная инструкция находится в README.md внутри.

## Содержимое

- Сайт на туркменском, русском и английском языках, каталог 13 строительных смесей.
- Backend и база D1: заявки, продукция, магазины, партнёры, видео и контакты.
- Закрытая админка: статусы обращений, заметки, выгрузка CSV, редактирование содержимого.
- Карта Туркменистана, данные и указание лицензий OpenStreetMap / Geofabrik и Natural Earth.
- Папка deliverables: логотипы, лицевые и оборотные SVG-макеты мешков, превью и архивы подготовленных вариантов.
- Исходники, схема базы, миграции, тесты и настройки сборки.

Секреты, локальная тестовая база и установленные зависимости в архив не включены. Данные настоящих заявок хранятся отдельно в базе сайта. Контакты компании пока не заполнены. Автоматические уведомления в почту и мессенджеры пока не подключены.

## Запуск

После распаковки установите Node.js версии 22.13 или новее, выполните npm ci, настройте локальный ADMIN_EMAIL и базу данных по README.md проекта, затем npm run dev. Для размещения требуется серверная среда, поддерживающая Cloudflare Worker и D1; GitHub Pages сам по себе backend не запускает.

Сайт: https://ylham-dagy.ochre-shell-9960.chatgpt.site
Управление: https://ylham-dagy.ochre-shell-9960.chatgpt.site/admin

Текущие SVG — разработанные макеты; технические показатели смесей подтверждаются производителем перед печатью.
